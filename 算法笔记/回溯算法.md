
## 1. 固定分叉型（不用 `for` 循环）

就是你说的“选 or 不选”，或者更广义地说：**每一步面前只有固定的 2 个（或少数几个）选项**，直接手写几段 `dfs` 分支就行。

- **特点**：决定清晰、分叉数固定，往往配合几个 `if` 做剪枝。
    
- **代表题目**：
    
    - 「78. 子集」：当前数**选** / **不选**
        
    - 「22. 括号生成」：当前位置放 **`(`** / 放 **`)`**
        
    - 「494. 目标和」：当前数前面放 **`+`** / 放 **`-`**
        

## 2. 横向 `for` + 纵向 `dfs` 型（多叉树）

站在当前位置，面前有一排候选项，需要用 `for` 循环把它们横向轮流试一遍。根据**题目在不在意顺序**，这里又分出最常用的两个小流派：

- **流派 A：可回头（`for` 从 `0` 开始 + `used[]` 数组）**
    
    - **适用场景**：**全排列**（在意顺序，`[1, 2]` 和 `[2, 1]` 算两个答案）。
        
    - **为什么**：选了 `2` 之后还能回头选前面的 `1`，所以 `for` 每次必须从 `0` 开始扫，靠 `used` 记事本防止同一个数被重复放进篮子。
        
- **流派 B：不回头（`for` 从 `startIndex` 开始，不需要 `used[]`）**
    
    - **适用场景**：**组合、切割字符串**（不在意顺序，`[1, 2]` 和 `[2, 1]` 算同一个答案）。
        
    - **为什么**：既然不讲究顺序，选完 `2` 以后就**只能往 `2` 后面选**，绝不回头看 `1`。只要给 `dfs` 多传一个 `startIndex` 参数，让 `for (int i = startIndex; ...)` 往后扫，天然就不会选重。
