## node != null 与 node.next ！= null

|**判断条件**|**含义**|**适用场景**|
|---|---|---|
|**`node != null`**|“当前这个节点本身还在不在？”|**需要处理每一个节点（包括最后一个）**，比如合并链表、遍历求和、打印链表|
|**`node.next != null`**|“我后面还有没有下一个节点？”|**要往后多看一步，或要停在尾节点上**，比如快慢指针找中点、把新节点插到链表末尾|
代码里只要出现了 `a.b.c`，前面的判断条件里就必须先写 `a != null && a.b != null`。
